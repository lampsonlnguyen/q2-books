# CrossPoint core on Q2

This directory contains the working CrossPoint reader source port, Linux/Q2 adapters, reader shell, host tests and MIPS packaging tools. See the [technical reference](../docs/TECHNICAL.md), [build guide](../docs/releasing.md) and [outstanding roadmap](../docs/ROADMAP.md) for current information. The old host-only prototype descriptions are superseded. Keep upstream license notices and avoid porting ESP32 firmware or replacing CrossPoint's EPUB layout engine.
