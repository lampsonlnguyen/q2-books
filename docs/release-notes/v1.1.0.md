Books 1.1.0 for the Shanling Q2: an ebook reader card app for Q2 Pod, built on the CrossPoint Reader engine ported to the Q2's Linux. Built by GitHub Actions after the GCC/Clang test suites and the Q2 MIPS/QEMU checks.

## Install
Extract the ZIP to the root of the Q2's SD card: it adds only the app's folder, `.books/` (program, fonts, certificates). Put your own `.epub` and `.txt` books in the card's `Books` folder. Do not flash it as firmware. In Q2 Pod the app is **Books** in the Library.

Upgrading from CrossPod: on its first start Books copies your reading positions, bookmarks, highlights, settings, recent books, `connected.conf` and `dictionary.tsv` from the old `.crosspod` folder, and moves `dictionaries/`.

## Changes since 1.0.0
- The release ZIP no longer carries test books: 1.0.0 put three test EPUBs (multilingual visibility, links and footnotes, Vietnamese prose) into your `Books` folder. If you installed 1.0.0, you can delete `Books-Multilingual-Visibility-Test.epub`, `Books-Links-and-Footnotes-Test.epub` and `vietnamese-prose.epub` from `Books`. The build still renders them on the Q2 MIPS binary before packaging.

Everything else is as in 1.0.0; see its release notes for features and known limits.

## Known limits
- Not yet measured on a physical Q2: battery, suspend and resume, memory over long sessions.
- Menus have no CJK glyphs (book text does). Dictionary matching ignores ASCII case only.
- A server certificate with a CN and no subjectAltName may be accepted, depending on the Q2's libcurl.
