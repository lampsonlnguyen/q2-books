Books 1.1.2 for the Shanling Q2: an ebook reader card app for Q2 Pod, built on the CrossPoint Reader engine ported to the Q2's Linux. Built by GitHub Actions after the GCC/Clang test suites and the Q2 MIPS/QEMU checks.

## Install
Extract the ZIP to the root of the Q2's SD card: it adds only the app's folder, `.books/`. Put your `.epub` and `.txt` books in the card's `Books` folder. Do not flash it as firmware. Settings, positions, bookmarks and highlights from 1.0 through 1.1.1 are kept.

## New since 1.1.1
- **Menus follow Q2 Pod's language:** the Vietnamese Language row in Reading settings is gone. Books reads Q2 Pod's own language setting. Translations ship for German, Spanish, French, Italian, Polish, Russian and Ukrainian, plus Vietnamese if Q2 Pod offers it. Other languages, and any language without a translation file on the card, stay in English.
- **Online catalogs:** add up to eight OPDS catalogs (for example Kavita or Calibre-Web) in `connected.conf`, with HTTP Basic sign-in sent only to the server that the credentials belong to.
- **Offline catalog cache:** catalog pages you have loaded are kept on the card (up to 64 pages, 8 MB), and a failed request is retried once before the app gives up.
- **Book details and covers:** a details screen shows a book's author, summary and cover, with covers cached on the card.
- **Folders:** the library can be sorted into folders, with a breadcrumb path to move back up. Up to 4000 books and 1024 folders are scanned, five levels deep.
- **Sync conflicts:** when the KOReader sync server and the Q2 disagree about a book's position by a clear margin, Books asks which one to keep.

## Known limits
- Not yet measured on a physical Q2: battery, suspend and resume, memory over long sessions, and catalog and cover loading over the Q2's Wi-Fi.
- Translations are not yet checked by native speakers; please report wording that is wrong or too long for a menu row.
- Menus have no CJK or Thai letters, so Japanese, Korean, Thai and Chinese menus stay in English (book text in those languages still shows).
- Highlights are not yet synced to the server.
- A server certificate with a CN and no subjectAltName may be accepted, depending on the Q2's libcurl.
