Books 1.2.2 for the Shanling Q2 is an ebook reader card app for Q2 Pod.

## Install

Extract `books-q2-v1.2.2.zip` to the root of the Q2's SD card. The ZIP installs the `.books/` app folder. Put your EPUB and TXT files in the card's `Books` folder. Existing reading positions, bookmarks and highlights are kept.

## New since 1.2.0

- **Smoother text:** menus, status bars and footers use Q2 Pod's TrueType fonts. Book text uses anti-aliased TrueType glyphs where compatible, with the existing CrossPoint glyphs as a fallback.
- **Layout for the rounded screen:** text, status and progress stay clear of the display corners. The reading page has more room without the control hints.
- **Night mode follows Q2 Pod:** Books uses the system's light or dark theme by default and remembers a manual override.

The v1.2.1 release contains source archives. This release provides the installable Q2 card package and its SHA-256 checksum.

## Known limits

Page-turn performance, battery use, suspend and resume, and long-session memory use still need validation on a physical Q2.
