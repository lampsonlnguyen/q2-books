# Books v1.2.3 for Shanling Q2

- Fixed malformed EPUB paragraphs that carried unclosed bold or italic formatting into the next paragraph. The app rebuilds existing chapter layout caches on next use.
- Added public-domain EPUB test excerpts with complex tables and Japanese ruby text, plus a rendered-page regression check for the paragraph fix.
- Included the smoother book and menu text, rounded-screen layout, and system-following night mode present in the v1.2.2 source.

## Install

Extract `books-q2-v1.2.3.zip` to the root of your Q2's microSD card. It installs the `.books/` card app for Q2 Pod. Keep your EPUB and TXT files in the card's `Books/` folder.

Physical-device page-turn performance, battery use, suspend and resume, and long-session memory use still need validation.
