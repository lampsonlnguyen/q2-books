# Books v1.2.5 for Shanling Q2

- Books menus follow the language selected in Q2 Pod under **System Settings → Language**. Books uses its own translations first, then matching labels from the active firmware language pack. English covers missing translations and unsupported glyphs.
- Completed Vietnamese translations for the current menu template.
- Added 35 core menu labels each for Japanese, Korean, Thai, Simplified Chinese, and Traditional Chinese.

## Install

Extract `books-q2-v1.2.5.zip` to the root of the Q2's microSD card. Open **Books** from the Q2 Pod Library. Keep EPUB and TXT files in `Books/`. With the q2-langs pack installed, choose your language in Q2 Pod's System Settings, then reopen Books.
