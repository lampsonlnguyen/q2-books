# Books v1.2.6 for Shanling Q2

- Smaller menu text leaves more room for labels.
- Reading fonts are available from 8 to 14 pt. The size picker cycles through
  the sizes installed for the current font. Switching fonts keeps the current
  size when available or selects the closest installed size.
- The SD-card package retains Books' menu translation tables.

Extract `books-q2-v1.2.6.zip` to the root of the Q2's microSD card. Open
**Books** from the Q2 Pod Library.
