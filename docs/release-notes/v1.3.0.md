# Books v1.3.0 for Shanling Q2

## New library experience

- Full-color Cover Flow with proportional book artwork, perspective, shading and reflections.
- Click-wheel animation, horizontal swipes, neighboring-cover selection and center-cover opening.
- Switch between Cover Flow (default) and List View from Home; the preference persists across restarts.
- Display book title, author and saved whole-book reading percentage. Older books gain a percentage when their reading position is next saved.
- Extract bounded PNG/JPEG thumbnails from unopened EPUBs during idle indexing; reuse SD caches and placeholders.
- Follow Q2 Pod theme and language; translated view controls across all 14 bundled language tables, with adaptive label sizing for rounded screen corners.
- Retain v1.2.6 typography improvements, reading positions, bookmarks, highlights, sorting, search, folders and OPDS.

## Validation and limitations

The release workflow publishes only after host GCC/Clang regression tests, Q2 MIPS/QEMU checks and archive verification pass. The previous M6 test build passed CI and received user visual feedback on the Home menu; the truncated view label was addressed in the subsequent patch. Full physical-Q2 testing, long-session RAM/CPU/battery measurements and native-speaker review remain outstanding. This is not a claim of completed hardware certification.

## Installation

Extract `books-q2-v1.3.0.zip` to the root of the Q2 microSD card, replacing application files while preserving existing reading data and settings. Open **Books** from Q2 Pod Library, then **Browse files**. Change the library view on Home. Verify the ZIP against its accompanying SHA-256 file.

See the README for the v1.4.0–v1.18.0 roadmap and outstanding hardware QA.
