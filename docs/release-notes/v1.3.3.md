# Books v1.3.3 (Shanling Q2)

- Browse Books now includes `userguide`, even on an empty card.
- Select it to download the current Q2 Pod User Guide EPUB from the dedicated guide release. Books keeps the last downloaded copy available offline.
- At launch, Books downloads a missing font pack for the selected Q2 Pod language when it uses a supported non-Latin script. If the download fails, Books opens in English and tries again the next time it starts.
