# Books v1.4.0 for Shanling Q2

## Changes

- Choose Grid View under Library View to browse a six-cover grid with reading progress, wheel navigation, and touch paging.
- JPEG covers and JPEG illustrations in EPUB reading mode use the Q2’s color screen.

- Books checks for a new edition when you open the Q2 Pod User Guide. If the guide is current, Books opens the SD-card copy without downloading the EPUB again.
- The guide remains available offline after the first successful download. Upgrading from v1.3.3 may download the guide once to record its version.

## Installation

Extract `books-q2-v1.4.0.zip` to the SD card root and verify the accompanying SHA-256 checksum.
