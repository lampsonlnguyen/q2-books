# Books v2.0.0 (Shanling Q2)

- Adds DRM-free legacy MOBI and PalmDOC/PRC import through CrossPoint.
- EXTH metadata, embedded covers and PNG/JPEG illustrations, heading/page-break navigation and legacy filepos links.
- Persistent import cache avoids repeated conversion; cover/title loading screen.
- Existing EPUB, TXT, Markdown and HTML reader retained.

Limits: 4 MiB decoded MOBI/PRC text with separate markup/image budgets; DRM, KF8-only and Huffman/CDIC unsupported. Progressive first-page reading during conversion is not implemented. Physical-device speed and memory validation remain outstanding.

Install the ZIP at the SD card root, preserve existing reading data, and verify SHA-256.
