# Books v0.10–v0.11 development notes (unreleased)

Merged on `main` after v0.9: roadmap milestones M2 (reading), M3 DI-01–03
(StarDict) and part of M4 (OPDS paging and search). Host tests, ASan and the
Q2 MIPS/QEMU card build pass. **None of it has been tested on a physical
Shanling Q2 yet**; there is no release until it has.

## Reading (v0.10, PR #39)

All in **Reading settings** (Center on a page):

| Row | What it does |
|---|---|
| Focus read | Upstream CrossPoint's partial-bold reading mode. Re-lays out the chapter and keeps your place. |
| Auto turn | Off, 10, 15, 20, 30, 45 or 60 s. Only while a page is shown (never under a menu or selection). Any key, wheel or touch restarts the interval; stops on the last page. |
| Go to % | A dialog: wheel moves 1 %, side keys 10 %, touch the bar to pick; Center jumps, Back cancels. 100 % opens the last page. |

- **Auto turn and Q2 Pod's idle timer:** Q2 Pod closes an app after about
  2 minutes without input. For hands-free reading longer than that, turn on
  Q2 Pod's **Smart Awake**. Books does not change Q2 Pod's power settings.
- **Page counter:** the footer shows `page/pages  NN%`. `~` before the page
  count means the chapter is still being laid out. The percentage and the bar
  are weighted by chapter size (as upstream CrossPoint), not by chapter count.
- **Plain text:** `.txt` files in `Books/` are listed with EPUBs on
  Books's shelf; a Books handoff given a `.txt` path opens it too. The first open wraps the file as a
  small EPUB in `.books/cache` (UTF-8, or Latin-1 when the file is not
  UTF-8; up to 32 MB), so bookmarks, highlights, percent and focus work as
  for EPUB. Each ~32 KB of text is one "part" in the chapter list.
  KOReader progress sync is meant for EPUB; it is not useful for TXT.
- The Books handoff reader (opened from Q2 Pod's Books) lists only the rows it
  can act on: the settings, Focus read, Auto turn and Go to %.

Settings are saved as `BOOKS-SETTINGS3`; older settings files still load
(the new options start off).

## Dictionaries (v0.11, PR #40)

Put StarDict dictionaries in either:

- `/mnt/mmc/.books/dictionaries/<name>/`, or
- `/mnt/mmc/Dictionaries/<name>/`

Each needs `<name>.ifo`, `<name>.idx` and `<name>.dict` or `<name>.dict.dz`;
`<name>.syn` (synonyms) is optional. Compressed `.idx.gz` is not supported:
unpack it with `gunzip`. Up to 16 dictionaries are used, in folder order.

- **Define** (select text → Define) searches every dictionary, then
  `dictionary.tsv`. Each match shows the headword and the dictionary's name;
  the wheel pages through long or multiple definitions.
- Matching ignores ASCII case, as StarDict does. Capitals outside ASCII (for
  example `Đ`) are not folded yet: select the word as the dictionary spells it.
- The first lookup in a dictionary builds a small index in
  `.books/cache` (`sd-*.cpidx`, about 4 bytes per 32 words); later opens
  reuse it; replacing the dictionary files rebuilds it.
- A damaged dictionary is skipped. To see why, run on a computer or over SSH:
  `books-reader --define <word>` with `BOOKS_STATE_DIR` pointing at a
  copy of `.books`.

**Fix in this release:** a long-press used to select the word on the line
below the one pressed; it now selects the pressed word.

## OPDS (PR #41)

- Catalog pages that link a next page end with **>> More results**.
- Catalogs that offer search (an OpenSearch description or an Atom search
  template) start with **[FIND] Search this catalog**: type with the shelf
  keyboard, then **DONE**. Back returns to the page you searched.
- Search and next links must be on the same server as the catalog (as
  downloads already must); others are ignored.

## Search keyboard (after v0.9.0-beta)

Library search and catalog search use the Q2's own T9 layout (Shanling's
4x4 keypad as Q2 Pod shows it): `,  abc  def  DEL` / `ghi  jkl  mno  ABC` /
`pqrs  tuv  wxyz  123` / `.?!  space  Done  CLR`. Tap a key, or turn the
wheel to it and press Centre. Press a letter key again within about a second
for its next letter (the strip under the field shows them); `ABC` switches
case and `123` makes each key type its digit.

## Your own fonts (after 1.1.0)

Put CrossPoint `.cpfont` files in a `Fonts` folder at the root of the card,
named `<Name>-12.cpfont` (and optionally `<Name>-10.cpfont`,
`<Name>-11.cpfont`). A font appears in Reading settings → Font, after the
built-in ones, when its 12 pt file is there. Names use letters, digits,
`_`, `-` and `.` (no spaces), 24 characters at most; up to 4 fonts, in name
order. Make the files with CrossPoint's font tools
(`lib/EpdFont/scripts` in crosspoint-reader), one file per point size: a
12 pt raster is never scaled to another size. TTF/OTF files are not read
directly. Changing or replacing a font file lays books out again.

## Notes and dictionaries (after 1.1.0)

- Reading settings → **Export notes** writes the book's highlights (with
  their words) and bookmarks to `Clippings/<book title>.txt` on the card.
  Highlights made before this version are listed without their words.
- Reading settings → **Dictionaries** turns each dictionary on or off.
- Lookups find a word whatever its case, including Vietnamese, Greek and
  Cyrillic capitals; a phrase with no entry is looked up by its first word.
- Each word you define is added to `.books/vocabulary.tsv` (time, word,
  headword, book).

## Menus in Vietnamese (after 1.1.0)

Reading settings → **Language** switches the menus between English and
Tiếng Việt (saved in `.books/language.conf`). Translated menus are drawn
with the reading font's own letters, so accents show; book titles, file
names and the T9 keys stay as they are.

## Q2 Pod's look (after 1.1.0)

Books takes its colours from Q2 Pod's theme (Settings → Display there):
Q2 Pod hands every card game its theme in `Q2_POPUP`, and Books draws its
pages, title and footer strips, chosen rows, keypad and highlights with it,
in Light Mode too:

- **Classic**: white pages, the glossy grey title strip, the blue gradient
  band with a white chevron on the chosen row.
- **Modern**: dark pages, the chosen row on the accent's rounded bar.
- **Minimal**: black pages, quiet grey rows, the chosen one white with a dot.

Menus use the reading font's smooth letters under a theme. Firmware older
than Q2 Pod's `Q2_POPUP` keeps Books' own look.
