# CrossPod v0.4.0 — EPUB fidelity and responsiveness

This version advances the **native CrossPoint** EPUB engine on Shanling Q2.
It does **not** ship ESP32 firmware or replace the Q2 operating system.

## Changes

- **Opening and resume:** Open the saved chapter directly instead of
  first parsing and rendering the first chapter only to discard it.
  Invalid or removed saved chapters still fall back to the start.
- **First page:** Preserve the original CrossPoint incremental Section parser:
  present the first available page without building the whole book.
- **Page turning:** The three-entry (~45 KB) raw raster cache retains
  text/images only, so return turns avoid rereading/repainting the page;
  progress and night-mode overlays remain fresh.
- **CPU/SD:** Prepare at most five pages ahead on idle ticks. Stop continuous
  large-chapter parsing when enough pages are buffered; restart when the
  reader catches up. Demand turns continue to request more pages.
- **EPUB CSS fidelity:** Pass saved line spacing, paragraph alignment,
  embedded-book CSS, and hyphenation to upstream `ReaderRenderSpec`.
  This fixes a previous override that forced CSS ON and ignored user
  line spacing/hyphenation preferences.
- **Multilingual:** Normalize book labels to NFC (Vietnamese, Hangul and
  other supported combinations) before UTF-8-safe clipping. Avoid splitting
  characters or stranding combining marks. Original CrossPoint bidirectional
  shaping and 14-script fallback infrastructure remain intact.
- **Measurement:** `crosspod-reader --bench <book.epub>` reports open time,
  first rendering time, repeated cached rendering, 64-turn sample duration,
  peak RSS and process block I/O.

## Verification

- GCC and Clang host regressions, including Unicode label tests and
  Section layout-option/cache-signature tests.
- Actual Q2-ABI MIPS cross-build under QEMU (not a device battery test).
- Two-pass cold/warm EPUB benchmarks (record measurements; do not assume
  warm opens are always faster due to host OS cache and test noise).
- MIPS EPUB rendering under two different reader configurations must change
  raster output (23,833 pixels changed in one QEMU run).
- Illustrated EPUB must render two inline images.
- Original CrossPoint multilingual font bundle: 14 of 14 script fallbacks
  loaded during QEMU validation.

## Limitations

This is a **beta**. Complex EPUB CSS/layout, very large or malformed books,
full-script font coverage and word shaping, touchscreen behavior, physical
device CPU/battery measurements, and sleep/resume still need field validation.
QEMU timings are not measured Q2 LCD or SD-card timings.

Do not flash the ZIP as firmware. Preserve your SD card and existing
`/mnt/mmc/.crosspod` directory before testing.
