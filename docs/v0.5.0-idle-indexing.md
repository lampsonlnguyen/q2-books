# Books v0.5.0 — Idle EPUB bookshelf indexing

## What changed

Books automatically discovers a never-opened EPUB's display title, author,
and declared cover artwork **while the bookshelf is idle**. The feature builds
on the existing recursive folder scanner, title/author search, recent history,
and 48x60 one-bit cover thumbnails.

- Indexing starts only after about 800 ms without user input.
- **One EPUB is attempted per idle cycle**; entries are visited once per
  application session. Returning to a book or scrolling the reader does not
  run the indexer.
- Uses the original CrossPoint ZIP, ContainerParser and ContentOpfParser
  implementation to locate the OPF title, author and cover-image item.
- Unlike opening a book, indexing does not create an EPUB Section, build the
  spine cache, load a chapter, render pages, or access any ESP32 firmware.
- On success, metadata is saved in the existing identity-checked .shelf cache
  and cover images are decoded once into the existing 48x60 monochrome cache.
- Existing cached metadata/cover files are reused; unchanged files are not
  rewritten, so scrolling does not trigger unnecessary SD-card writes.
- The Q2 home panel and searchable library refresh after a book is indexed.
- Invalid or unsupported EPUBs are skipped; they remain visible under their
  filename and can still be opened by the existing reader.

## Boundaries and practical limits

This is an incremental *best-effort idle indexer*, not a background thread or
real-time scheduler. A single ZIP/OPF/cover decoding operation is synchronous
and can briefly occupy the event loop; Q2 hardware responsiveness should be
tested on large SD-card libraries.

- Maximum 512 books in the initial shelf scan (existing limit).
- Maximum EPUB size for automatic indexing: 128 MiB.
- Maximum uncompressed container.xml: 256 KiB.
- Maximum uncompressed OPF: 1 MiB.
- Maximum compressed cover payload after inflation: 2 MiB, with PNG/JPEG
  decoder pixel safeguards already enforced in Books.
- Book identities are checked against the current file size and mtime.
- No network access, full EPUB cover scraping, covers synthesized from a page,
  DRM bypass, or modification of book contents.

The indexer records a successful cache but does not permanently record
failed attempts. A failed book is tried once in a given session. The next
launch can try again; books with no declared cover may retain a placeholder.

## Regressions and device validation

The tests generate an EPUB3 fixture with an OPF title, Vietnamese author,
and a declared PNG cover image. They index that EPUB without ever opening
a chapter, verify title and thumbnail caches, check a second pass performs
no cache writes, then change the file timestamp and verify invalidation.

Host GCC/Clang and Q2 MIPS/QEMU run this regression; the Q2 test-build ZIP
continues to include the mandatory multilingual visibility EPUB.

Physical Q2 checklist: launch the bookshelf with a never-opened EPUB in
`/mnt/mmc/Books`, leave it idle, then confirm the real title, author and
cover appear. Test a large directory, search by the newly indexed author,
and check the wheel remains responsive when indexing is ongoing. Also retest
the 129-page forward/back navigation stability fix.

The latest officially tagged release remains v0.4.0 until a v0.5.0 release
is explicitly published.
