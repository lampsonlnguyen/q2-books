# Books v0.5.0 — Bookshelf search and nested EPUB folders

## Included in this development increment

- Discover up to 512 EPUBs across up to 256 subfolders, with at most
  five directory levels below /mnt/mmc/Books. Files and directories
  reached through symlinks are not followed.
- Find books by filename or *cached* OPF title/author. Search uses the
  original CrossPoint Unicode NFC normalization, including decomposed
  Vietnamese filenames. ASCII is case-insensitive; general Unicode
  case-folding is not yet implemented.
- Entirely self-contained on-device search keyboard:
  1. From **Home**, open **Browse files**.
  2. Tap the bookshelf title/header to open **Search library**.
  3. Rotate the Q2 click wheel to highlight a letter or digit.
  4. Press the center button to add the highlighted character.
  5. Use SP (space), DEL (delete), CLR (clear) or DONE; Back also
     returns to the filtered results.
  6. From the results list, use wheel/center or touch to open a book.
- No Wi-Fi, external keyboard, Q2 Pod text-input widget or modified
  Q2 Pod firmware is needed.
- Existing bookmarks, positions, thumbnails, CSS, Unicode fonts and
  long-scroll render-cache stability fixes are not replaced.

## Performance and safety

- The discovery pass uses lstat, bounds filename/path lengths, does
  not parse a book, does not follow symlinks, and stops at the limits.
- Cached OPF metadata is read lazily, only when the visible bookshelf
  row is drawn or a search query needs it. Each book is checked at most
  once per shelf session. Search is intentionally small and local:
  512 book maximum, 24 ASCII-character search limit.
- EPUB source files are never written or changed during discovery or
  filtering. Previously cached OPF metadata is invalidated when a
  book's size or modification timestamp changes.
- Search cannot find author/title metadata of **unopened** EPUBs until
  an indexing pass has extracted their metadata. Original filenames
  are always searchable.

## Known remaining v0.5.0 work

- Lightweight, throttled OPF metadata and cover indexing for *unopened*
  EPUBs, without performing full Section pagination at bookshelf startup.
- Physical Q2 UI and repeated wheel/touch stress testing.
- Potential Unicode case-folding/word-search improvements, large
  library indexing, persistent search preferences and optional folder
  hierarchy navigation. Recursive discovery is **not** a folder tree UI.
- A release tag must not be issued until both CI and on-device
  regression validation have finished.

## Build verification

- Host: GCC and Clang CrossPoint Core CI; includes nested-folder
  traversal, depth/entry bounds, symlink exclusion, EPUB extension
  matching, OPF title/author search and decomposed Vietnamese filenames.
- Q2: MIPS32r2/NaN2008 build with stock-Q2 rootfs and QEMU reader tests,
  plus a runnable SD-card artifact.

The v0.4.0 prerelease remains the latest official beta until v0.5.0
is explicitly tagged. The Q2 alpha workflow artifacts are development
builds only; they do not flash or replace the Linux firmware.
