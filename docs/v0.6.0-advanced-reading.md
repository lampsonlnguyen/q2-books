# Books v0.6.0 — Advanced reading, phase 1

This increment implements **internal EPUB links and footnotes** using original
CrossPoint `Page::links`, `Page::footnotes`, and `Section::findAnchor()`
rather than replacing the EPUB renderer or Q2 Pod reader framework.

## Reader controls on the Shanling Q2

- **Touch:** tap a laid-out EPUB link to jump to its destination. Ordinary
  taps outside link regions retain existing left/right page-turn controls.
- **Click wheel:** open Reading settings with the center button. Choose
  **Page links** to browse links and footnote references on the current page.
  Rotate to select; press center to follow.
- **Return:** choose **Return link** from Reading settings to return to the
  saved page prior to following the link.
- Links can target anchors in the current XHTML spine or a different XHTML
  spine. Only internal archive destinations are accepted. URLs with schemes,
  queries, untrusted traversal and unsupported percent-encoded filenames
  are refused instead of opening the wrong destination.
- A bounded in-memory stack retains at most 16 link-jump locations. It does
  not write to the SD card for each tap beyond the existing normal reading
  progress persistence. The stack is not retained after closing the book.
- EPUB footnotes are shown as navigable references, **not yet** as a
  full-text popup overlay.

## Tests

- Pure href regression: anchor, relative spine links, traversal and scheme
  rejection, no accidental external URLs.
- Generated two-spine EPUB with same-page anchor, cross-chapter link and an
  EPUB3 `epub:type="noteref"` footnote.
- Host and Q2 MIPS/QEMU regression opens the real EPUB with CrossPoint
  Section, confirms serialized Page links, follows the cross-spine link, and
  returns to its original location.
- Existing long-scroll, CSS, font and 30-language test-EPUB checks remain
  part of the Q2 hardware-alpha workflow.

## Work still remaining for full v0.6.0

Precise touch-text selection, selection handles, highlights anchored to
visible-text offsets, highlight persistence across re-pagination,
dictionary lookups, full-text footnote popovers, and broad real-book
validation remain unfinished. The page model already provides stable
visible-text offsets but implementing accurate selection needs word/glyph
geometry and direction-aware hit testing. Do not claim those capabilities
exist yet.

This is a standalone Q2/Linux SD-card reader application. It does not port
CrossPoint ESP32 firmware, ESP32 OTA code, or modify Shanling's kernel.
