# Books v0.6.0 — Advanced reading completion

Books remains an SD-card Linux/MIPS application that uses **original
CrossPoint** EPUB `Section`, `Page`, `PageLine`, and `TextBlock` layout.
The ESP32 firmware, bootloader, FreeRTOS, and OTA flashing components are
deliberately not built or linked.

## New in the second v0.6.0 increment

### Word selection and persistent highlights

Every CrossPoint `TextBlock` already preserves the original chapter's
Unicode *visible-text codepoint offsets* and each shaped word's position.
Books uses these offsets and font-measured word widths to hit-test
touchscreen gestures and draw highlights over rendered words.

- **Touch:** press and hold a word for at least 450 ms or drag between words
  (28 or more logical pixels) to select a word or text range. Short taps
  still follow links or change pages.
- **Wheel:** Center → Reading settings → **Select text**. Spin the wheel
  to find the starting word; press Center once. Spin again to extend the
  selection, then press Center for actions.
- Actions: **Highlight**, **Define**, **Remove** (existing overlapping
  highlight), and **Cancel**.
- Highlight records are identity-checked against EPUB file size/mtime and
  stored atomically under `/mnt/mmc/.books/progress-<hash>.highlights`.
  They are keyed by OPF spine and visible-codepoint [begin,end) ranges.
- Up to 128 non-overlapping records per book, merging overlapping/touching
  ranges. They survive application restart and re-pagination after changing
  font/line-spacing/margin settings. Changes to EPUB bytes invalidate
  cached highlights rather than attaching them to the wrong text.
- Highlight records are kept in reader RAM after their first load, so each
  page render does **not** reread the SD-card annotation file. No highlight
  write occurs on an ordinary page turn.

### Offline dictionary

- Select a word → **Define**. A local popup searches
  `/mnt/mmc/.books/dictionary.tsv`, a UTF-8 tab-separated word and
  definition per line. ASCII case is ignored; Unicode words match by
  exact UTF-8 spelling (not language-specific inflection).
- The ZIP includes `.books/dictionary-starter.tsv` with a small set
  of English and Vietnamese reading terms. It is used if no custom
  `dictionary.tsv` exists. Copy or rename the starter and append your own
  entries to create a larger offline dictionary.
- File lookup is capped at 50,000 lines; each definition at 500 bytes.
  No network, paid API, or operating-system dictionary service is required.
- This does **not** ship a full universal dictionary for all languages.

### Full text footnote popover

Books already followed EPUB internal links in v0.6 phase 1. Now:
- Tapping a reference recognized by CrossPoint's `Page::footnotes`, or
  selecting that reference via **Page links**, opens a popup containing
  the referenced XHTML element's actual text.
- Back dismisses the popup without leaving the reading location; Center
  follows the link if the note is too long or preview unavailable.
- XML/Expat parses the targeted <aside>/<li>/<p> element and expands XML
  entities; only the matching anchor subtree is displayed.
- ZIP resource paths are restricted to internal EPUB items; inflated XHTML
  is capped at 256 KiB and extracted preview text at 1,500 bytes.
- Broken or unsupported HTML shows a fallback message and still allows
  ordinary link navigation. EPUB sources are never changed.

## QA and test book package

The Q2 card ZIP includes BOTH:
- `Books/Books-Multilingual-Visibility-Test.epub` (30 language samples)
- `Books/Books-Links-and-Footnotes-Test.epub` (same-page anchor,
  cross-chapter link, and an EPUB3 footnote)

Host CI checks highlight persistence/merging/invalidation, Unicode dictionary
lookups, and footnote HTML extraction. Q2 MIPS/QEMU checks real selected-word
ranges, saved highlight rendering, cross-chapter navigation, multilingual
fonts, and a long book page-turn stress regression.

## Limitations requiring hardware validation

- Selection is **word-granular and within one rendered page**. Dragging from
  one chapter/page into another is not implemented.
- Shaped complex scripts, ruby text, and vertical or unusual EPUB layouts
  may require additional coordinate tuning on the physical Q2.
- Highlights are monochrome inverse-contrast rectangles; the Q2 display
  has no text selection handles or colored highlighter.
- CrossPoint's legacy emergency renderer does not supply full word offsets;
  annotations require the normal original Section rendering engine.
- The dictionary starter is deliberately small; users can import larger
  properly licensed TSV lexicons.
- Footnote popovers are bounded excerpts and cannot render rich HTML
  images, embedded CSS, tables or arbitrary JavaScript.

No v0.6.0 tag should be declared complete until GCC/Clang and Q2 MIPS
tests pass and the release is explicitly published. Physical-device
confirmation remains distinct from simulated tests.
