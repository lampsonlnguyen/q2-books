# v1.16 — Language-aware hyphenation

Branch directly from v1.10 series. Existing EPUB language metadata, inline lang/xml:lang scopes, and eleven licensed Liang pattern tries are reused. Rules are static read-only data; no heap-loaded dictionary corpus, downloads, or new dependencies. Language tags are bounded and validated; ISO aliases and case-insensitive primary tags remain supported. User Off and heading suppression disable automatic dictionary rules even during emergency wrapping. Unsupported language emergency wraps do not synthesize hyphens; combining marks and joiners are protected at emergency boundaries. Ukrainian uppercase normalization corrected. Section cache version bumped so layouts rebuild; existing source-coordinate resume remains unchanged. Added focused regression assertions. Full multilingual layout, nested language scopes, RTL, anchor and physical-device memory testing remain pending; no claim of complete Unicode grapheme segmentation or new Vietnamese dictionary.
