# v1.8 M1 — Reading status

Use existing per-book whole-book progress and identity-validated resume positions, plus recent successful opens. A valid 100% whole-book percentage is Completed; a smaller valid percentage, valid saved position (including legacy BOOKS1), or recent successful open is Reading. A book with none of this evidence is Unread. Chapter-local fractions never establish completion. Missing files are excluded by the library scan. Automatic status follows current progress: rereading below 100% returns to Reading. Explicit overrides and status filters belong to M2; no progress or history files are modified by M1. History remains path-based, so a replaced file at the same path can still count as Reading if in recent history, but cannot become Completed from stale progress. Existing tests cover zero, near-completion, exact completion, rereading and invalidated file identity.

## M2 and M3

Library > Reading status selects All, Unread, Reading or Completed. Counts cover all real books in the scanned library (not the virtual User Guide), independent of collection and search filters. Library > Mark reading status applies an explicit Unread or Completed override, or Automatic status removes it. Manual overrides take priority until cleared and use the book's existing size/mtime identity. No resume files are changed. Overrides are stored per book, and the chosen status filter is stored in a separate versioned settings file. Active filters intersect with collection, favorites, series and search; the virtual guide remains accessible. All books in the Library menu clears group and status filters; the All option in Reading status clears only the status filter. Status results are cached for the lifetime of the shelf and refreshed after the reader closes or a manual mark changes. No device timing benchmark has been performed yet.
