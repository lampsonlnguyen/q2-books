# v1.8 M1 — Reading status

Use existing per-book whole-book progress and identity-validated resume positions, plus recent successful opens. A valid 100% whole-book percentage is Completed; a smaller valid percentage, valid saved position (including legacy BOOKS1), or recent successful open is Reading. A book with none of this evidence is Unread. Chapter-local fractions never establish completion. Missing files are excluded by the library scan. Automatic status follows current progress: rereading below 100% returns to Reading. Explicit overrides and status filters belong to M2; no progress or history files are modified by M1. History remains path-based, so a replaced file at the same path can still count as Reading if in recent history, but cannot become Completed from stale progress. Existing tests cover zero, near-completion, exact completion, rereading and invalidated file identity.
