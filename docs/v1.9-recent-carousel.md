# v1.9 M1 — Recent-book carousel foundation

Reuse BOOKS-RECENT1, capped at 20 paths, and resolve them against the scanned library in most-recent-first order independent of shelf sort. Skip missing books without modifying history, deduplicate displayed indices, and retain the existing Current book fallback when no recent books are present. Only successful reader opens update history. Reuse identity-validated RGB565 flow-cover cache and one displayed thumbnail; no full-size cover preloading or new image cache. The existing default cover remains available if cached artwork is missing. A previously displayed book's cover must not suppress artwork indexing for a different selected recent book. No new persistent format. M2 will refine Home layout; M3 will refine controls; M4 will measure device latency and validate layouts. Path-based history does not track renames and may identify a replacement at the same path; no automatic identity migration is introduced.

## M2 — Home layout

A compact 91-pixel-high card uses one cached color cover (60×78), title, author, numeric progress and a progress bar when known. The right navigation strip appears only with multiple recent books; boundary arrows are hidden. The three original Home actions remain below the card. With no books, the card shows No books yet and leaves Browse files and Options available. Touch bounds and thumbnail composition use the same layout constants. Physical display and theme testing remain pending.
